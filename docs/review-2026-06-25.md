## Summary

Go 1.26 BIST (Borsa İstanbul) analysis engine, 165k LOC / 978 files. `internal/ta` is 108k LOC (66% of the codebase). Build passes (`go build ./...` clean, one harmless cgo sqlite warning).

**Verdict:** Well-disciplined for its size. The domain layer is genuinely clean (no infra leakage), error handling is consistent (73% of `fmt.Errorf` wrap with `%w`), concurrency is textbook (proper worker pools + ctx cancellation), no global mutable state. The real issues are **abstraction discipline**, **god files**, **test holes in the decision math**, and **repo hygiene** — not foundational rot.

---

## P1 — Worth fixing

### 1. `ta` (compute core) imports upward into infrastructure
Graph confirms `ta→services` (57 calls), `ta→datasources` (32), `ta→kapingest` (19). Example: `internal/ta/analysis/engine.go:15-16` imports `services/matriksformations` and `services/pricequality`. This inverts dependency direction and makes the TA engine un-unit-testable without live data services.

**Fix:** Inject a small `PriceQualityProvider`/`FormationsProvider` interface instead of importing concrete `services/*`.

### 2. Repository ports are defined but bypassed
`internal/repositories/contracts.go` (7 interfaces) is consumed only by `internal/application/documentingestion`. The real workload binds to concrete `internal/storage` — graph shows `services→storage` 161 calls, `services→repositories` 0. The ports & adapters layering is aspirational.

**Fix:** Either make `EquityStore` satisfy the interfaces and depend on them, or delete the unused contracts.

### 3. One library panic
`internal/services/tradingview/charts.go:687` — `mustJSON` calls `panic(err)` on a marshal failure. Library code shouldn't abort the process.

**Fix:** Return `(string, error)` and propagate.

### 4. Decision math has zero tests
All four `internal/analysis/{fundamental,risk,technical,valuation}/scoring.go` and `internal/confidence/score.go` (the `score < 0.75` review gate) have no test files. These encode the actual investment-decision logic and are small pure functions — cheap to cover.

**Fix:** Add table-driven tests pinning expected scores for representative inputs.

## P2 — Should address

### 5. God files
`internal/ta/storage/professional_report.go` is **9,549 lines**; its `reportLabel` function is **719 lines** (a switch-as-translation-table). `engine.go` 6,057, `professional.go` 5,196, `investorqa.go` 5,121.

**Fix:** Extract `reportLabel`/`reportText` into data maps or generated code; split `AnalyzeSymbol` (201 lines) and `computeNextSessionForecastModel` (195) into named steps.

### 6. Magic numbers in scoring
`internal/confidence/score.go:18-62` — weights (`0.20`, `+0.35`, `-0.25`) and the `0.75` gate are bare literals. `indicators.go:520` hardcodes CCI `0.015`; Fibonacci levels duplicated as both map keys and float multipliers.

**Fix:** Promote to named `const` so the gate/weights are greppable and tunable in one place.

### 7. `context.Background()` in hot paths
`engine.go:2566`, `ta/storage/writer.go:315`, `ta/ensemble/ensemble.go:36` start fresh root contexts instead of threading the caller's ctx — severs cancellation/timeout propagation.

**Fix:** Thread the request `ctx` through the scan/forecast pipeline.

### 8. Near-duplicate matchers
`internal/ta/indicators/scanner_matchers.go` (2,646 LOC) and `internal/ta/patterns/scanner_matchers.go` (2,172) share large copy-pasted scaffolding.

**Fix:** Extract shared matcher/alias helpers into a common `internal/ta/scanmatch` package.

## P3 — Repo maintenance

- **Tracked artifacts that shouldn't be:** `prompt.json` (80KB) and dated `reports/*.txt`/`.json` are committed. These look like generated/runtime output. Consider `.gitignore` + `git rm --cached`.
- **No build/quality tooling:** no `Makefile`/`justfile`, no `.golangci.yml`, no test CI. The only workflow is `.github/workflows/kap-attachment-worker.yml`. A `go test -race ./...` + `golangci-lint` CI job would lock in the already-good concurrency.
- **Commit hygiene:** recent history is `fixes`, `fi`, `fi`, `fixes`. Meaningful messages help future debugging.
- **`ta` package fragmentation:** risk is computed in 3 places (`ta/risk`, `analysis/risk`, `quant`); `internal/analysis/*` is a thin parallel re-implementation that doesn't even import `ta`. Pick one canonical home per concern; collapse `internal/ingestion` into `kapingest`.
